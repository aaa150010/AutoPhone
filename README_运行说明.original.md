# GPT 注册中心（原 Plus Bind Tool V1.0.3 说明）

运行 `PlusBindTool_V1.0.3.exe`。程序会自动选择可用的本机端口并打开界面；复制多个文件夹可同时运行。

首次启动需要管理员按机器码签发 `license.key`。请把该文件与 EXE、`node.exe`、`node_chain.dat` 放在同一目录。

本发行包不包含任何邮箱、短信平台、SUB2、代理、国家、结果或日志数据。首次启动后的本地配置默认接码国家为空。

当前 macOS 版本使用 `start.command` 启动本机 WebUI，浏览器标题为“GPT 注册中心 | Free + 接码”。界面分为接码工作台和独立 Free 注册工作区；Free 可选择全协议或 RoxyBrowser，默认 3 并发、最大 5 并发，并为每个账号固定一个代理和出口 IP。

Free 邮箱取件与注册住宅代理分离：默认通过 `http://127.0.0.1:7897` 访问取件 URL，也可在 Free 配置中选择直连。普通接码与 Free 共用邮箱 OTP 解析和旧验证码排除引擎，但配置、邮箱池、任务、日志和运行数据互不混用。

邮箱取件 URL 返回 `/pickup` 或 `/latest` 前端壳时，程序会继续请求同源 `/api/messages` 和邮件详情接口，按时间读取最新验证码；日文邮件、HTML/JSON 正文、全角数字和下划线化发件人均由同一解析器处理。跨域跳转、TLS、超时和 HTTP 失败会明确归到邮箱取件节点，取件地址参数和验证码不会写入日志。
